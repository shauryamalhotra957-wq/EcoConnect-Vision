# Contributing

Thanks for improving EcoConnect Vision.

## Development setup

1. Fork or clone the repository.
2. Create a focused branch from `main`.
3. Create and activate a Python virtual environment.
4. Install Jupyter and the notebook's documented dependencies.
5. Open `biodeg.ipynb` and restart the kernel before validation.

## Validation

Run the notebook from a clean kernel, confirm that every required file uses a repository-relative path, and clear incidental outputs before committing. Document dataset provenance, preprocessing changes, and evaluation metrics.

## Pull requests

Describe the data and model impact, validation environment, and reproducibility considerations. Never commit private datasets, credentials, or unlicensed model artifacts.
